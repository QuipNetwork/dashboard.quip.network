# v0.3.0 — Drop PoW Epoch Abstraction; Substrate Becomes Canonical

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the PoW-epoch abstraction (EpochSelector, epoch_status, backfill-worker, nodes_snapshot, all `/api/v1/telemetry/*` calls), make the substrate worker the sole block writer using `quantum_pow.ProofAccepted` + `BlockWinner` event pairs, and slim the REST integration down to a single `/api/v1/status` poll for self-identity + a single `/api/v1/stats` poll for self mining stats — shipping the smallest possible v0.3.0.

**Architecture:** The chain becomes the authoritative source for what blocks exist. The substrate worker subscribes to `system.events`, scans each block for one `BlockWinner` plus the matching `ProofAccepted` (correlated by `(miner, energy_milli)`), reads `LastProofBlock` storage to derive mining time, decodes the winning `submit_proof` extrinsic to extract nonce, and inserts a complete `BlockRecord` in one shot. The REST tip-worker shrinks to a heartbeat poller that writes only self-identity (`miner_hardware` row) and aggregate counters (`minerStats` in observability). A new `miner_hardware` table holds per-account hardware/category data sourced from `/api/v1/system`, with a `source` enum (`self|peer-query|chain`) ready for future versions to populate other nodes' data without schema changes.

**Tech Stack:** Bun runtime, TypeScript, `@polkadot/api` 15.9.1 (already pinned), Hono server, React + Vite + Zustand, SQLite + Postgres adapter parity, `bun test`.

## Context

**Why this change:**

- The previous v0.2.0 release (this MR's predecessor) added substrate-derived fields and patched the `(epoch, block_index)` data model to coexist with substrate state. That release shipped under the assumption that the legacy `/api/v1/telemetry/*` REST endpoints would continue to provide block/peer data. **They don't.** The v0.2 miner image removed them:
  - `/api/v1/telemetry/status` → 404
  - `/api/v1/telemetry/epochs` → 404
  - `/api/v1/telemetry/nodes` → 404
  - `/api/v1/telemetry/epochs/{epoch}/blocks/{n}` → 404
- The chain is now the authoritative source for per-block PoW data. `pallet-quantum-pow` (`pallets/quantum-pow/src/lib.rs`) emits one `BlockWinner` event per substrate block in `on_finalize` (the winning proof) and one or more `ProofAccepted` events (every accepted submission). Together they carry `energy_milli, diversity_milli, valid_solution_count, quality_milli, miner, reward, submitted_at`. Nonce sits in the `submit_proof` extrinsic call data. Topology constants (`num_nodes, num_edges`) come from `quantum_pow.RegisteredTopology` storage.
- The PoW *epoch* (the 16-char hex grouping with `EpochSelector` + `epoch_status` + stale-fork tagging + backfill plan) has **no chain-side equivalent**. quip-protocol-rs uses BABE epochs (substrate consensus rotation, ~4h) and PoW difficulty windows (~100-block adjustment), but neither maps to the legacy 16-char "epoch" concept. The user chose to delete the abstraction outright rather than reverse-engineer a mapping.
- `minerCategory` ("CPU"/"GPU"/"QPU") is not on chain. The v0.2 miner REST exposes it per-node via `/api/v1/system.miners[].type`. Today the indexer can only know its own node's category. Later miner versions will publish a queryable list of active miners per block, and chain storage will likely surface this too. The schema accommodates the future by holding hardware data in a separate `miner_hardware` table with a `source` enum field (`self|peer-query|chain`).
- `ecdsaPublicKey`, `nodeName`, peer-list `address`, geolocation — all gone. Chain identity is SS58 only. The dashboard now renders SS58 addresses everywhere a peer-list address used to appear.

**Intended outcome:** a single v0.3.0 release that drops the legacy abstractions, makes substrate the canonical block source, and ships the smallest viable codebase. Operators wipe `data/telemetry.db` (v5 → v6 is a clean break); production Postgres runs the forward migration in `server/migrate.ts`.

```ts
// SPDX-License-Identifier: AGPL-3.0-or-later
//
// Types for v0.3 dashboard. The chain (quip-protocol-rs spec >=101) is the
// canonical source for per-block PoW data via the `quantum_pow` pallet's
// `BlockWinner` + `ProofAccepted` events. The miner's `/api/v1/status` /
// `/api/v1/system` / `/api/v1/stats` REST endpoints supply self-identity and
// aggregate counters only — there is no peer-aggregation surface in v0.2/v0.3.

export type MinerCategory = "CPU" | "GPU" | "QPU" | "OTHER";

// Source of a `miner_hardware` row. `self` is the only producer today
// (tip-worker polling `/api/v1/system`); `peer-query` and `chain` are
// reserved for future versions that fetch other nodes' hardware data
// without requiring a schema change.
export type MinerHardwareSource = "self" | "peer-query" | "chain";

export interface BlockRecord {
  // PoW solution hash. Unique per block, used as the table PK.
  blockHash: string;

  // Substrate-side anchor. In v0.3 substrate is the canonical source, so
  // every block has these populated (never null). u64 fits in INTEGER for
  // ~292B years at 6s blocks, so plain number is safe here (unlike u128
  // balances which we keep as strings).
  substrateBlockNumber: number;
  substrateBlockHash: string;
  substrateParentHash: string;

  // Unix seconds from substrate `timestamp.now`.
  timestamp: number;
  // SS58 account ID of the winning miner (BlockWinner.miner).
  minerId: string;
  // energy_milli / 1000 from BlockWinner.
  energy: number;
  // diversity_milli / 1000 from the correlated ProofAccepted.
  diversity: number;
  // From ProofAccepted.valid_solution_count.
  numValidSolutions: number;
  // From ProofAccepted.quality_milli — integer-units (no division). The chain
  // emits this directly; UI formats with 3 decimal places when displayed.
  qualityMilli: number;
  // Substrate blocks between this win and the previous (LastProofBlock-derived).
  miningTime: number;
  // Block reward, u128 as string for precision.
  reward: string;
  // u64 nonce, string-encoded to preserve precision. Extracted from the
  // winning submit_proof extrinsic call data.
  nonce: string;
  // From quantum_pow.RegisteredTopology storage. Constant per chain unless
  // an upgrade rotates topology — still stored per-block for self-contained
  // historic rows.
  numNodes: number;
  numEdges: number;
  // Difficulty snapshot at time of write — copied from `quantum_pow.Difficulty`
  // so a single block row is self-contained for charts/replay.
  difficultyEnergy: number;
  minDiversity: number;
  minSolutions: number;
  // True once the substrate chain has finalized this block. Monotonic.
  finalized: boolean;
}

export interface RuntimeVersion {
  specName: string;
  specVersion: number;
  transactionVersion: number;
  implName: string;
  lastRuntimeUpgrade: string | null;
}

export interface ChainHead {
  bestBlockNumber: string;
  bestBlockHash: string;
  finalizedBlockNumber: string;
  finalizedBlockHash: string;
  finalityLag: number;
  runtime: RuntimeVersion;
  updatedAt: string;
}

export interface BabeEpochState {
  epochIndex: number;
  currentSlot: string;
  epochStartSlot: string;
  slotsPerEpoch: number;
  currentSlotInEpoch: number;
  authorityCount: number;
}

export interface BabeAuthorityRecord {
  accountId: string;
  displayName: string | null;
}

export interface ChainMinerRecord {
  accountId: string;
  deposit: string;
  proofsSubmitted: string;
  proofsWon: string;
  rewardsEarned: string;
  // Joined server-side from `miner_hardware.node_id` when the chain account
  // matches a known hardware row. Null when no match (chain account has no
  // miner_hardware row, e.g. another operator's node not yet peer-queried).
  // Today only self is populated; future peer-query / chain-surface versions
  // populate other entries without schema changes.
  telemetryNodeAddress: string | null;
}

export interface DifficultyRecord {
  observedAtBlock: string;
  difficultyEnergy: number;
  minDiversity: number;
  minSolutions: number;
  minQuality: number;
  observedAt: string;
}

// Hardware descriptor for a single miner node. Populated from the miner's
// own `/api/v1/system` REST endpoint today (self only); future versions will
// also populate from peer queries or chain storage.
export interface MinerHardwareRecord {
  accountId: string;            // SS58
  nodeId: string;               // human-readable, e.g. "quip-miner-pow"
  miners: Array<{ id: string; type: MinerCategory }>;
  // Convenience: the dominant miner type for badges/colors. Derived from
  // miners[] by the writer (tip-worker today) — most miners run one backend.
  primaryType: MinerCategory;
  source: MinerHardwareSource;
  observedAt: string;
}

// Aggregate counters from the miner's `/api/v1/stats`. Held in observability,
// not its own table — these are high-cardinality and only meaningful for
// "right now" (self) until peer-query lands.
export interface MinerStats {
  totalBlocksAttempted: number;
  totalBlocksWon: number;
  winRate: number;
  totalMiningTime: number;
  avgMiningTime: number;
  // From the controller sub-object — drops down a level in the wire format
  // so the dashboard can render flat tiles.
  headsObserved: number;
  contextsDispatched: number;
  resultsReceived: number;
  proofsSubmitted: number;
  staleDrops: number;
  submissionErrors: number;
}

export interface IndexerObservability {
  // Chain head as last reported by the local quip-node's /api/v1/status.
  // Lets the UI catch a divergent local node (node thinks tip is X; substrate
  // worker observes Y). Null until first successful poll.
  chainHeadFromNode: number | null;
  lastStatusFetchAt: string;
  // Most recent successful block insert by the substrate worker.
  lastBlockInsertAt: string | null;

  // Substrate worker heartbeat — null when QUIP_VALIDATOR_RPC_URL is unset.
  lastSubstrateEventAt: string | null;
  bestBlockHeight: string | null;
  finalizedBlockHeight: string | null;
  chainConnected: boolean;

  // From /api/v1/stats. Null pre-first-fetch or when the local node is
  // unreachable. Single source today (self); peer-query future may upgrade
  // to a Record<accountId, MinerStats>.
  minerStats: MinerStats | null;
}

export interface TelemetryResponse {
  blocks: BlockRecord[];
  // SS58 of the locally polled quip-node. From /api/v1/status.ss58_address.
  selfAddress: string | null;
  indexer: IndexerObservability | null;
  serverTime: string;
  chainHead: ChainHead | null;
  babeEpoch: BabeEpochState | null;
  babeAuthorities: BabeAuthorityRecord[];
  chainMiners: ChainMinerRecord[];
  recentDifficulty: DifficultyRecord[];
}

export interface ErrorResponse {
  error: string;
  detail?: string;
}
```

```ts
export function parseIndexerObservability(
  raw: string,
  adapterName: AdapterName,
): IndexerObservability | null {
  let parsed: unknown;
  try { parsed = JSON.parse(raw); }
  catch { return null; }
  if (!parsed || typeof parsed !== "object") return null;
  const p = parsed as Record<string, unknown>;
  const isStr = (v: unknown): v is string => typeof v === "string";
  const isNullableStr = (v: unknown): v is string | null =>
    v === null || typeof v === "string";
  if (!isStr(p.lastStatusFetchAt)) return null;
  if (!isNullableStr(p.lastBlockInsertAt)) return null;
  if (!isNullableStr(p.lastSubstrateEventAt)) return null;
  if (!isNullableStr(p.bestBlockHeight)) return null;
  if (!isNullableStr(p.finalizedBlockHeight)) return null;
  if (typeof p.chainConnected !== "boolean") return null;
  const chainHeadFromNode =
    typeof p.chainHeadFromNode === "number" ? p.chainHeadFromNode : null;
  const minerStats = parseMinerStats(p.minerStats);
  return {
    chainHeadFromNode,
    lastStatusFetchAt: p.lastStatusFetchAt,
    lastBlockInsertAt: p.lastBlockInsertAt,
    lastSubstrateEventAt: p.lastSubstrateEventAt,
    bestBlockHeight: p.bestBlockHeight,
    finalizedBlockHeight: p.finalizedBlockHeight,
    chainConnected: p.chainConnected,
    minerStats,
  };
}

function parseMinerStats(raw: unknown): MinerStats | null {
  if (!raw || typeof raw !== "object") return null;
  const r = raw as Record<string, unknown>;
  const n = (v: unknown): number | null => (typeof v === "number" ? v : null);
  const a = n(r.totalBlocksAttempted);
  const w = n(r.totalBlocksWon);
  if (a === null || w === null) return null;
  return {
    totalBlocksAttempted: a,
    totalBlocksWon: w,
    winRate: n(r.winRate) ?? 0,
    totalMiningTime: n(r.totalMiningTime) ?? 0,
    avgMiningTime: n(r.avgMiningTime) ?? 0,
    headsObserved: n(r.headsObserved) ?? 0,
    contextsDispatched: n(r.contextsDispatched) ?? 0,
    resultsReceived: n(r.resultsReceived) ?? 0,
    proofsSubmitted: n(r.proofsSubmitted) ?? 0,
    staleDrops: n(r.staleDrops) ?? 0,
    submissionErrors: n(r.submissionErrors) ?? 0,
```

```ts
// SPDX-License-Identifier: AGPL-3.0-or-later

import type { DatabaseAdapter } from "../api/db/adapter";
import type {
  MinerCategory,
  MinerHardwareRecord,
  MinerStats,
} from "../src/types/telemetry";
import type { IndexerConfig } from "./config";
import { AuthError, type NodeStatus, QuipClient } from "./client";
import { IndexerState } from "./state";

export interface TipWorkerDeps {
  config: IndexerConfig;
  client: QuipClient;
  db: DatabaseAdapter;
  state: IndexerState;
  now?: () => number;
}

export async function runTipLoop(deps: TipWorkerDeps, signal: AbortSignal): Promise<void> {
  const intervalMs = deps.config.tipPollIntervalSec * 1000;
  while (!signal.aborted) {
    try {
      await runTipIteration(deps);
    } catch (e) {
      if (e instanceof AuthError) throw e; // fatal for tip worker
      console.error("[indexer/tip] iteration failed:", e instanceof Error ? e.message : e);
    }
    await sleep(intervalMs, signal);
  }
}

export async function runTipIteration(deps: TipWorkerDeps): Promise<void> {
  const { client, db, state } = deps;
  const nowMs = (deps.now ?? Date.now)();
  let status: NodeStatus | null = null;
  let stats: MinerStats | null = null;
  try {
    status = await client.getStatus();
    if (status.ss58Address) {
      const prior = await db.getSelfAddress();
      if (prior !== status.ss58Address) {
        await db.setSelfAddress(status.ss58Address);
      }
      const hardware: MinerHardwareRecord = {
        accountId: status.ss58Address,
        nodeId: status.nodeId,
        miners: status.miners,
        primaryType: derivePrimaryType(status.miners),
        source: "self",
        observedAt: new Date(nowMs).toISOString(),
      };
      await db.upsertMinerHardware(hardware);
      state.observability.chainHeadFromNode = status.chainHeadNumber;
    }
  } catch (e) {
    // 502/connection errors are non-fatal; flush observability so the
    // heartbeat ages monotonically and the UI can see staleness.
    console.warn("[indexer/tip] /api/v1/status failed:", e instanceof Error ? e.message : e);
  }

  try {
    stats = await client.getStats();
    state.observability.minerStats = stats;
  } catch (e) {
    console.warn("[indexer/tip] /api/v1/stats failed:", e instanceof Error ? e.message : e);
  }

  state.observability.lastStatusFetchAt = new Date(nowMs).toISOString();
  await db.setIndexerObservability(state.observability);
}

function derivePrimaryType(miners: Array<{ type: MinerCategory }>): MinerCategory {
  if (miners.length === 0) return "OTHER";
  // Counts per type; ties broken by enum order (CPU < GPU < QPU < OTHER).
  const counts: Record<MinerCategory, number> = { CPU: 0, GPU: 0, QPU: 0, OTHER: 0 };
  for (const m of miners) counts[m.type]++;
  return (Object.entries(counts) as Array<[MinerCategory, number]>)
    .sort((a, b) => b[1] - a[1])[0]![0];
}

function sleep(ms: number, signal: AbortSignal): Promise<void> {
  return new Promise((resolve) => {
    const t = setTimeout(resolve, ms);
    signal.addEventListener("abort", () => { clearTimeout(t); resolve(); }, { once: true });
  });
}
```

```ts
async subscribeBlockEvents(cb: (e: BlockEvents) => void): Promise<UnsubFn> {
  const api = this.requireApi();
  // Use the finalized stream as the trigger so a reorg never causes us to
  // insert a dropped block. Substrate finalization lags by 1-2 blocks in
  // typical operation; the cost is ~6-12s extra latency per insert vs. new
  // heads.
  const unsubFn = await api.rpc.chain.subscribeFinalizedHeads(async (header) => {
    const blockNumber = header.number.toNumber();
    const blockHash = header.hash.toHex();
    const parentHash = header.parentHash.toHex();

    const [signedBlock, eventsAt, timestampAt] = await Promise.all([
      api.rpc.chain.getBlock(header.hash),
      api.query.system.events.at(header.hash),
      api.query.timestamp.now.at(header.hash),
    ]);

    let winner: BlockWinnerEvent | null = null;
    const proofs: ProofAcceptedEvent[] = [];
    for (const rec of eventsAt as unknown as Array<{ event: { section: string; method: string; data: unknown[] } }>) {
      const { section, method, data } = rec.event;
      if (section !== "quantumPow") continue;
      if (method === "BlockWinner") {
        const [miner, reward, energyMilli, submittedAt] = data;
        winner = {
          miner: (miner as { toString(): string }).toString(),
          reward: (reward as { toString(): string }).toString(),
          energyMilli: Number((energyMilli as { toString(): string }).toString()),
          submittedAt: (submittedAt as { toString(): string }).toString(),
        };
      } else if (method === "ProofAccepted") {
        const [miner, energyMilli, diversityMilli, valid, quality] = data;
        proofs.push({
          miner: (miner as { toString(): string }).toString(),
          energyMilli: Number((energyMilli as { toString(): string }).toString()),
          diversityMilli: Number((diversityMilli as { toString(): string }).toString()),
          validSolutionCount: Number((valid as { toString(): string }).toString()),
          qualityMilli: Number((quality as { toString(): string }).toString()),
        });
      }
    }
    if (!winner) return; // block had no PoW win; skip

    // Extract nonce from the winning submit_proof extrinsic. The block's
    // signed extrinsics include all `quantum_pow.submit_proof(proof)` calls;
    // the winner is the one whose proof matches (miner, energyMilli).
    const nonce = extractNonce(signedBlock, winner);

    cb({
      blockNumber,
      blockHash,
      parentHash,
      timestamp: Math.floor(Number((timestampAt as { toString(): string }).toString()) / 1000),
      winner,
      proofs,
      nonce,
    });
  });
  return () => { (unsubFn as unknown as () => void)(); };
}

async getLastProofBlockAt(blockHash: string): Promise<number> {
  const api = this.requireApi();
  if (!api.query.quantumPow?.lastProofBlock) return 0;
  const codec = await api.query.quantumPow.lastProofBlock.at(blockHash);
  return Number(codec.toString());
}

async getTopology(): Promise<TopologyInfo | null> {
  const api = this.requireApi();
  if (!api.query.quantumPow?.registeredTopology) return null;
  const codec = await api.query.quantumPow.registeredTopology();
  const opt = codec as { isSome?: boolean; unwrap?: () => Record<string, { toNumber(): number }> };
  if (!opt.isSome) return null;
  const inner = opt.unwrap();
  return {
    nodeCount: inner.node_count?.toNumber() ?? inner.nodeCount?.toNumber() ?? 0,
    edgeCount: inner.edge_count?.toNumber() ?? inner.edgeCount?.toNumber() ?? 0,
  };
}
```

```ts
function extractNonce(signedBlock: unknown, winner: BlockWinnerEvent): string {
  // signed.block.extrinsics is an array of GenericExtrinsic. Find the one
  // whose call is quantumPow.submit_proof and whose payload's miner+energy
  // matches the winner. The proof struct (see pallets/quantum-pow/src/types.rs:
  // QuantumProof { topology_hash, miner_id, nonce, solutions, ... }) holds the
  // nonce field we want.
  const block = (signedBlock as { block: { extrinsics: Array<{
    method: { section: string; method: string; args: unknown[] };
  }> } }).block;
  for (const ext of block.extrinsics) {
    if (ext.method.section !== "quantumPow" || ext.method.method !== "submit_proof") continue;
    const proof = ext.method.args[0] as { miner_id?: { toString(): string }; nonce?: { toString(): string } };
    // miner_id is the proof author's SS58 in v0.2 schema; energy_milli isn't
    // on the proof struct directly (it's derived from solutions). For
    // disambiguation when multiple proofs match the same miner, prefer the
    // first one — the chain guarantees only one wins per block.
    if (proof.miner_id?.toString() === winner.miner) {

    }
  }
  return "0";
}
```

- **Telemetry node join (open):** `ChainMinerRecord.telemetryNodeAddress` populates from `miner_hardware.node_id`. Today only self has a `miner_hardware` row (source=`self`); other accounts show as null.
